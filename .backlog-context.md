# Checklist checked-state IS readable via the Markdown export — pull silently reports every checked box as unchecked (Priority 3 | Status: in_progress)

## Description
## Summary

`nodes_to_markdown.py:85` hardcodes checkbox items as unchecked, with a comment saying rendering unchecked is "the only honest option here". That was a reasonable conclusion from the Docs API, but it is **not correct** — and the consequence is that pull silently misreports the state of every checked item.

## What is actually true

| Read path | Checked state visible? |
|---|---|
| `documents.get()` (Docs API v1) | **No** |
| `files.export` → `text/plain` | No (`* item` for both) |
| `files.export` → `text/html` (docspan's current pull path) | No (`content:"●  "`, identical ``) |
| `files.export` → **`text/markdown`** | **Yes — `- [x]` vs `- [ ]`** |

The Docs API limitation is real and worth keeping documented: in a doc with checked and unchecked items in the *same list*, the two paragraphs are byte-identical under `documents.get()` — same `listId`, same `bullet` dict, no `strikethrough`. `CHECKBOX` appears once in the entire v1 discovery document, as the write-only `bulletPreset: BULLET_CHECKBOX` enum.

But the Markdown exporter is a **different renderer** and carries three useful signals at once:

```
- [ ] Native cb one          <- native checkbox, unchecked
- [x] Native cb two          <- native checkbox, CHECKED
* Disc bullet plain          <- ordinary bullet uses "*", not "-"
* \[ \] Disc bullet literal  <- literal brackets are backslash-escaped
```

So checkbox-ness, checked state, and disambiguation from literal `[ ]` text are all recoverable. Nesting survives as indentation. Verified on a real checklist document: 31 checked / 96 unchecked, matching the UI.

Pairing the ordered native-checkbox paragraphs from `documents.get()` against the ordered `- [x]`/`- [ ]` lines from the export matched **exactly** — 100% on count and text — across several documents including nested lists, an interleaved table, mixed bullet presets, and literal-bracket decoys. So the join a fix would depend on is sound.
